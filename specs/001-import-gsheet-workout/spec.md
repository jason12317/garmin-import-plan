# 功能規格書：匯入 Google Sheet 訓練計畫至 Garmin Connect

**功能分支**: `001-import-gsheet-workout`  
**建立日期**: 2026-01-08  
**狀態**: 草案  
**輸入**: 用戶描述：「身為GARMIN 使用者 我想要能夠將教練給我的GOOGLE SHEET匯入到GARMIN CONNECT的訓練計畫中，這將會是一項反向工程因為GARMIN並未開放API給個人使用者，但已明確知道建立訓練計畫的API是https://connect.garmin.com/gc-api/workout-service/workout」

## 用戶場景與測試 *(強制)*

### 用戶故事 1 - 基礎單一訓練匯入 (優先級：P1)

身為一名健身的人，我希望將 Google Sheet 上的教練建立的肌肉訓練菜單同步到 Garmin Connect，這樣我就不需要手動在 Garmin 網頁上重新輸入複雜的訓練步驟。

**為什麼是此優先級**: 這是本工具的核心價值。如果無法成功將 Sheet 內容轉換為 Garmin 格式並透過 API 寫入，則整個項目就沒有意義。

**獨立測試**: 使用一個預設格式的 Google Sheet，執行匯入指令後，在 Garmin Connect 網頁版的「訓練 (Workouts)」中能看到完全正確的新增項目。

**驗收場景**:

1. **假設** 使用者已將 Google Sheet 下載為本地 CSV/XLSX 檔案且完成 Garmin 登入，**當** 執行匯入指令並指定檔案路徑時，**則** 系統應解析檔案中的第一日訓練計畫並在 Garmin 中建立。
2. **假設** 檔案路徑無效或格式錯誤，**當** 執行匯入時，**則** 系統應顯示明確的錯誤訊息告知原因。

---

### 用戶故事 2 - 批量計畫匯入 (優先級：P2)

身為一個參加馬拉松訓練營的學員，我希望一次將教練提供的整週的訓練計畫全部匯入，省去逐一匯入的時間。

**為什麼是此優先級**: 提升效率的關鍵。教練通常提供的是一整週的計畫。

**獨立測試**: 提供一個包含多行數據的 Sheet，驗證 Garmin Connect 中是否建立了對應數量的訓練項目。

**驗收場景**:

1. **假設** Google Sheet 包含 7 天的訓練內容，**當** 執行批量匯入時，**則** Garmin Connect 應出現 7 個獨立的訓練項目。

---

### 邊界情況

- **連結無效**: 當 Google Sheet 連結為私有或無效時，系統應提示權限不足。
- **重複匯入**: 如果相同的訓練已經存在（名稱與日期相同），系統應詢問是否覆蓋或跳過。
- **欄位缺失**: 如果必填欄位（如：訓練類型）空白，應中止該項目的匯入並報錯。

## 需求 *(強制)*

### 功能需求

- **FR-001**: 系統「必須」(MUST) 支持讀取公開或具備讀取權限的 Google Sheet。
- **FR-002**: 系統「必須」(MUST) 支持解析 Garmin Workout API 所需的核心欄位：名稱、類型 (Running/Cycling 等)、步驟 (Step)、目標內容 (Goal)。
- **FR-003**: 系統「必須」(MUST) 使用 Garth 函式庫進行安全身份驗證。
- **FR-004**: 系統「必須」(MUST) 調用 `https://connect.garmin.com/gc-api/workout-service/workout` 進行數據寫入。
- **FR-005**: 系統「必須」(MUST) 在 Google Sheet 格式不符時提供錯誤日誌。
- **FR-006**: 系統「必須」(MUST) 遵循固定標題行的 Google Sheet 欄位格式。核心標題包含：`動作`, `組數`, `重量`, `次數`。
- **FR-007**: 系統「必須」(MUST) 支持解析逗號分隔的次數（如 `8,7,6,6`）並對應為多個訓練步驟。
- **FR-008**: 系統「必須」(MUST) 支持解析「自身」重量（0kg）以及簡單的計算算式（如 `25+2.3`）。

### 關鍵實體 *(若涉及數據則包含)*

- **WorkoutPlan**: 代表整個匯入任務，包含多個訓練項目與來源連結。
- **WorkoutItem**: 單一訓練實體，包含 Garmin API 所需的 JSON 結構屬性。
- **GarminSession**: 用於 API 調用的身份驗證令牌或會話狀態。

## 成功標準 *(強制)*

### 可衡量的成果

- **SC-001**: 使用者可以在 30 秒內完成 7 天計畫的同步。
- **SC-002**: 排除網路問題，匯入數據與 Sheet 原始數據的準確性應為 100%。
- **SC-003**: 系統應能在不依賴 Garmin 官方 SDK 的情況下，穩定維護與 Garmin API 的通訊。

## Clarifications

### Session 2026-01-08

- Q: Google Sheet 解析格式？ → A: 使用固定標題行 (Fixed Header) 進行解析。
